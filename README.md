## 🚀 Featured projects

### [ZamMarket](https://github.com/john-chola/ZamMarket) · [Live demo](https://zammarket.vercel.app)
A progressive web app connecting charcoal sellers and buyers in Lusaka (final year project).
Real-time chat · offline listings with background sync · voice listing in English, Nyanja and Bemba · seller trust scores · admin dashboard

`React` `Redux Toolkit` `Node.js` `Express` `MongoDB Atlas` `Socket.io` `Cloudinary` `PWA`

### [Clinic Queue](https://github.com/john-chola/clinic-queue) · [Live demo](https://clinic-queue.vercel.app)
Patients scan a QR code, take a number, and watch their place in the queue live, so they can wait outside instead of guessing.
Live wait estimates · one-tap "Next patient" for staff · waiting-room display that reads numbers aloud · reports

`React` `Node.js` `Express` `MongoDB` `Socket.io` `Jest`

### [Pact](https://github.com/john-chola/pact)
A mobile app for 7-day accountability sprints in small groups of developers.
Daily check-ins · streaks · live group feed · push-notification nudges · rules enforced in the database

`React Native` `Expo` `TypeScript` `Supabase` `PostgreSQL`

### [Bookstore POS](https://github.com/Smart17-ui/Book_Store_POS) *(team project)*
A point-of-sale system for bookstores covering sales, inventory, returns, branches, staff roles and PDF reports.

`Django REST Framework` `React` `Tailwind CSS` `Pandas`
